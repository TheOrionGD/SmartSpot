# SmartSpot - Render Deployment Guide

This guide provides step-by-step instructions for deploying the **SmartSpot Backend** to [Render](https://render.com) and connecting your **Flutter Client** (Mobile, Web, Desktop) to the live service.

---

## 📋 Render Blueprint Specification (`render.yaml`)

Below is the complete export format blueprint defined in [`backend/render.yaml`](file:///o:/PROJECTS/College/smartspot/backend/render.yaml):

```yaml
# Exported from Render on 2026-08-24T06:07:41Z
version: "1"
projects:
- name: College-Projects
  environments:
  - name: Production
    services:
    - type: web
      name: smartspot-backend
      runtime: node
      repo: https://github.com/TheOrionGD/SmartSpot
      plan: free
      envVars:
      - key: NODE_ENV
        value: production
      - key: PORT
        value: "10000"
      - key: JWT_SECRET
        generateValue: true
      - key: DB_FILE
        value: ./data/smartspot.json
      - key: BREVO_API_KEY
        sync: false
      - key: MAIL_FROM
        sync: false
      - key: MAIL_FROM_NAME
        value: SmartSpot
      - key: CORS_ORIGIN
        sync: false
      region: oregon
      buildCommand: npm install
      startCommand: npm start
      healthCheckPath: /health
      disk:
        name: smartspot-data
        mountPath: /app/backend/data
        sizeGB: 1
      autoDeployTrigger: commit
      rootDir: backend
```

## 🚀 Option A: Automated Blueprint Deployment (Recommended)

Render supports Infrastructure-as-Code via `render.yaml` located at [`backend/render.yaml`](file:///o:/PROJECTS/College/smartspot/backend/render.yaml).

### Step 1: Push Code to GitHub / GitLab
Ensure your project repository is pushed to a remote git provider (e.g. `https://github.com/TheOrionGD/SmartSpot`).

### Step 2: Create a New Blueprint Instance
1. Log into your **[Render Dashboard](https://dashboard.render.com)**.
2. Click **New +** in the top-right corner and select **Blueprint**.
3. Connect your **SmartSpot** repository.
4. Render will automatically detect [`backend/render.yaml`](file:///o:/PROJECTS/College/smartspot/backend/render.yaml).
5. Review the service plan and configuration details.

### Step 3: Configure Required Environment Variables
Render will prompt you for any un-synced environment variables declared in `render.yaml`:
- **`BREVO_API_KEY`**: Your API key from Brevo for sending security emails.
- **`MAIL_FROM`**: The sender email address (e.g., `godfrey.cs23@krct.ac.in`).
- **`CORS_ORIGIN`**: Set to `*` or your frontend client URL.

> [!NOTE]
> `JWT_SECRET` is automatically generated by Render during blueprint creation.

### Step 4: Deploy
Click **Apply**. Render will allocate the persistent disk, build the Node environment, install dependencies, and launch your API service.

## 🛠️ Option B: Manual Web Service Deployment

If you prefer setting up the Web Service manually via the Render Web Interface:

### Step 1: Create a Web Service
1. In the Render Dashboard, click **New +** → **Web Service**.
2. Connect your Git repository (`TheOrionGD/SmartSpot`).

### Step 2: Configure Service Settings
- **Name**: `smartspot-backend`
- **Region**: `Oregon (us-west)`
- **Branch**: `main`
- **Root Directory**: `backend`
- **Runtime**: `Node`
- **Build Command**: `npm install`
- **Start Command**: `npm start`
- **Health Check Path**: `/health`

### Step 3: Configure Environment Variables
Add the following key-value pairs in the **Environment** tab:

| Variable | Value / Description |
| :--- | :--- |
| `NODE_ENV` | `production` |
| `PORT` | `10000` *(Render default port)* |
| `JWT_SECRET` | Secret key (e.g. standard 64-char hex string) |
| `DB_FILE` | `./data/smartspot.json` |
| `CORS_ORIGIN` | `*` (or your Flutter Web URL `https://your-app.web.app`) |
| `BREVO_API_KEY` | *(Optional)* Your Brevo SMTP API key |
| `MAIL_FROM` | `godfrey.cs23@krct.ac.in` |
| `MAIL_FROM_NAME` | `SmartSpot` |

### Step 4: Add Persistent Disk (Crucial for Data Retention)
1. Go to the **Disks** section under your web service configuration.
2. Click **Add Disk**.
3. **Name**: `smartspot-data`
4. **Mount Path**: `/app/backend/data`
5. **Size**: `1 GB`

## 📱 Connecting the Flutter App to Render Backend

Once your backend is deployed, Render will provide a live URL such as:
`https://smartspot-backend.onrender.com`

### 1. Verification
Test the health check endpoint in your browser or curl:
```bash
curl https://smartspot-backend.onrender.com/health
```
**Expected Response:**
```json
{
  "status": "OK",
  "service": "SmartSpot API",
  "timestamp": "..."
}
```

### 2. Running & Building Flutter with Live API URL

Pass the `API_BASE_URL` at compile/run time via `--dart-define`:

#### 🏃 Run Locally with Render Backend:
```powershell
flutter run -d windows --dart-define=API_BASE_URL=https://smartspot-backend.onrender.com
```

#### 🌐 Build Flutter Web:
```powershell
flutter build web --release --dart-define=API_BASE_URL=https://smartspot-backend.onrender.com
```

#### 🤖 Build Android APK:
```powershell
flutter build apk --release --dart-define=API_BASE_URL=https://smartspot-backend.onrender.com
```

## 🔍 Troubleshooting & Pro Tips

> [!TIP]
> **Free Tier Cold Starts**: Render's free tier spins down idle web services after 15 minutes of inactivity. The first request after sleep may take ~30 seconds.

> [!IMPORTANT]
> **Persistent Disk Requirement**: Without mounting a persistent disk to `/app/backend/data`, Render's ephemeral filesystem will reset `smartspot.json` on every redeploy or restart.
